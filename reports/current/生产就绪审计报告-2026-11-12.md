## 执行摘要

**总评：C+（接近 B-）—— 工程底子扎实，距「生产级」尚有一道明确的坎。**

这不是一个写得差的项目：原子写盘、BCrypt、Cookie 标志、属主鉴权端到端完整、统一异常映射、89.9% 指令 / 70.8% 分支覆盖率且有门禁、密钥仅 env 注入、XSS 防线完整、契约单一源、依赖面极小。按「本地演示环境」（应用自述）衡量，它超出预期。

## 一、严重 / 高危

### F1（严重）· Provider 管理端点无管理员门槛，准入报告泄漏 endpoint

- **实码取证**：`travel-server/src/main` 全量 grep `hasRole|hasAuthority|@PreAuthorize|@Secured|ROLE_ADMIN|GrantedAuthority` → **0 命中，全仓无角色模型**。五个管理端点均在 `interfaces/rest/AgentCapabilityController.java:72`（admission）、`:78`（reload）、`:90`（probe）、`:96`（shadow）、`:103`（activate），统一落在 `infrastructure/security/SecurityConfiguration.java:59` 的 `.anyRequest().authenticated()` 下。
- **后果**：注册开放 + 无角色 ⇒ **任意注册用户**可重读配置、发携带服务端 Bearer token 的真实探针、消耗配额跑影子、改注册表状态、读完整准入报告；失败报告的 `RuleFailure.actual` 含 endpoint/host 原值。G4「人工确认启用」的设计意图被 HTTP 层架空。
- **方向**：管理端点加角色或独立管理鉴权；admission 对非管理员脱敏 `actual`。**须先决策鉴权模型**（角色 vs 独立管理鉴权，与开放注册联动）——这是唯一需要拍板才能动的安全边界项。

### P1（高危·新增）· Spring Boot 3.5.7 已 EOL，落在多个 2026 CVE 版本区间

- **实码取证**：`pom.xml:7` = `3.5.7`。**3.5 线 OSS 支持已于 2026-06-30 终止**（endoflife.date / 搜狐 / 华为云多源一致），同批停维的还有其锁定的 Spring Framework 6.2、Spring Security 6.5。今后**不再有新免费安全补丁**。
- **CVE 适用性（按真实依赖面核定，非泛泛告警）**：本项目依赖仅 `web + security + validation`，**无 Actuator / devtools / fastjson / CloudFoundry**，源码与 yml **无 `${random.value}` / `ApplicationPidFileWriter` / 持久会话**。据此：

| CVE | 级别 | 受影响区间 | 触发前置 | 本项目 | 适用 |
|---|---|---|---|---|---|
| 2026-22733 | High | 3.5.0–3.5.11 | 业务端点误映射到 CF Actuator 路径 | 无 CF / 无 Actuator | **否** |
| 2026-40975 | Medium | <3.5.14 | `${random.value}` 当密钥 | 未使用 | **否** |
| 2026-40977 | Medium | <3.5.14 | `ApplicationPidFileWriter` | 未使用 | **否** |
| 4.0.6/3.5.14 批次之 Critical | Critical | 3.5.x | Actuator 端点未授权访问 | 无 Actuator 依赖 | **否** |
| 2026-16723 | Critical | fastjson 1.2.68–1.2.83 | 用 fastjson | 用 Jackson | **否** |
| 2026-22731 | — | 3.5.0–3.5.11 | 触发条件未完全核实 | 版本在区间内 | **需人工复核** |

- **诚实结论**：**当前配置下无确证可直接利用的 CVE**——极小依赖面反而挡掉了最严重的 Actuator 类漏洞（这是优点）。真正风险是**结构性**的：EOL 后任何新披露的 Tomcat / Framework / Security 漏洞都不会再回补到 3.5 OSS。
- **方向**：升级 **4.0.8+ 或 4.1.x**（整条依赖链一起动，非改版本号；4.0 要 JDK 21+、Jackson 3、包路径重构，社区经验 6–14 周）；**过渡止血**可先跟到 **3.5.16**（3.5 线最后开源补丁）。`CVE-2026-22731` 与批次 Critical 的确切组件请对 `spring.io/security` 人工复核后再定级。

### F2（高危）· 登录跳转开放重定向（`/\` 绕过，晨间已 Node 实证）

- **实码取证**：`travel-server/src/main/resources/static/index.html:467` `if (v && v.charAt(0) === '/' && v.charAt(1) !== '/') return v;`——只挡 `//`，不挡 `/\`。WHATWG URL 把 `/\evil.com` 归一为协议相对 `//evil.com`。:464 注释自称「避免开放重定向」，实则不全。
- **方向**：一行修复——`new URL(v, location.origin)` 解析后校验 origin 一致，或白名单路径前缀。

### F7（高危）· 登录 / 注册无速率限制

- **取证**：`travel-server/src/main` grep `RateLimit|Bucket4j|resilience4j|throttl|loginAttempt` → 0 命中。可在线暴力破解。
- **方向**：按账号 + IP 计数退避（内存计数即可，无需引依赖）。
