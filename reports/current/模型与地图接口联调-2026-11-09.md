## 一、高德地图接口（真实调用）

### 调用方式

经应用自有端点，非裸 API 调用：注册本地测试账号 → 登录拿会话 → 打需登录的地点与天气端点。沙箱出网正常。

### 实测证据

| 端点 | 入参 | 结果 |
| --- | --- | --- |
| `GET /api/location/places` | `keywords=西湖&city=杭州&limit=1` | 返回真实 POI（杭州西湖风景名胜区），含 `lat/lon`、`coordinateSystem=GCJ-02`、`address`、`tel` |
| `GET /api/location/weather` | `city=杭州` | 返回 `adcode=330100` 与逐日 `days[]` 明细（当日 多云 12~7℃） |
| `GET /api/location/status` | 公开 | `configured=true`，证明密钥已注入应用 |

### 来源清楚

天气响应 `source` 字段标注「高德地图 Web 服务 · 天气预报」；规划响应 `sources` 含「高德地图 Web 服务 · 天气预报」。

### 失败有说明（专项验证）

故意使用无效密钥打 `restapi.amap.com/v3/place/text`，高德返回 `infocode=10001 INVALID_USER_KEY`。应用 `AmapClient.explain()` 将其翻成中文提示：「密钥无效或与绑定平台不符，请检查 AMAP_KEY」。应用侧：高德未配置时抛 `AmapUnavailableException`，全局异常处理映射为 HTTP 503。

## 二、DeepSeek 模型（真实调用）

### 调用方式

`GET /api/agent/status` 确认 `modelConfigured=true` 后，经 `POST /api/agent/plan`（`withAdvice` 默认开启）触发真实模型请求。模型配置见 `application.yml`：`url=https://api.deepseek.com/v1`、`model=deepseek-chat`。

### 实测证据

| 项 | 结果 |
| --- | --- |
| 配置状态 | `/api/agent/status` 返回 `modelConfigured=true`，能力列表含「文字建议」 |
| 真实调用 | `POST /api/agent/plan {"destination":"杭州","days":2}` 返回 HTTP 200 |
| 文字建议 | `advice` 非空（507 字），内容含天气判断与具体票价（雷峰塔成人 40 元、三潭印月登岛 20 元），为模型上下文生成而非模板拼接 |
| 来源清楚 | 响应 `sources` 含「DeepSeek deepseek-chat」 |
| 配套产物 | `candidates` 10 条、`dailySchedules` 2、`checks` 2、`budgetEstimate` 与 `questions`（结构化补问）齐备 |

### 缺密钥有说明（专项验证）

未配置 `DEEPSEEK_API_KEY` 时，`/api/agent/status` 返回 `modelConfigured=false` 并明确提示不生成文字建议；规划接口降级为只加 `notices` 而不 503。已在上轮验证，本轮密钥注入后该降级路径关闭。
