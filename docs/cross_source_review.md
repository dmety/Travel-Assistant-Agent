## 四、检索匹配加固规则（落地约束）

下游检索 / 合并逻辑**必须**满足以下约束（AND 全满足才允许自动合并）：

```text
跨源合并条件（全部满足才自动合并）：
  1. name_zh 归一化后完全一致（去空格、全半角、繁简统一）
  2. province 相同
  3. city 相同  —— 或 同省内两坐标 haversine 距离 ≤ 1km
  4. source 不冲突（同 amap 或同 OSM 才自动；mixed 需人工）
  5. same_name_risk 为空（一旦命中风险标记，必须人工确认，禁止自动合并）

坐标字段：KB 使用 lat / lon（WGS-84 或 GCJ-02，以 coordinateSystem 字段为准，
混合源比对前需先统一到同一坐标系再算距离）。

优先级：命中 same_name_risk != null 或 merge_review != null 的记录，
在检索结果中应明确标注「同名风险提示」，由前端/运营人工介入，不静默合并。
```
