## 契约与命令

`data/kb_modules/*.json` 是编辑源，`data/china_attractions.json` 是产物。`tools/kb_modules.py` 管三条命令：

```bash
python -B tools/kb_modules.py --check      # 门禁默认：模块合成结果是否与主库逐字节一致
python -B tools/kb_modules.py --assemble   # 改完模块，原子写回主库
python -B tools/kb_modules.py --split      # 主库被旧脚本改动后，反向对齐模块
```

`--check` 比对字节，不是语义近似。原主库是 `ensure_ascii=False` 加紧凑分隔符的单行 JSON，共 5,787,278 字符。`layout.json` 记下顶层键顺序和每条记录的字段顺序模板，合成结果因此能逐字节复现历史主库。三种模式都先做内存往返校验，字段漏分组或 id 不对齐会直接报错，不静默丢数据。

## 维护规则

1. 改票价只动 `facts.json` 里对应 `records[i]` 的一条，然后依次跑 `--assemble`、重建索引、`--check`。
2. 新增字段先登记到 `LAYERS`。否则 `--split` 和 `--assemble` 会拒绝执行，避免字段被丢掉。
3. 绕过模块直接改主库，或改了模块没合成，`tools/gate.sh` 第一步就失败。
4. `build_unified_kb.py` 和 `tools/kb/apply_*.py` 这些旧脚本仍直接写主库。跑完必须用 `--split` 对齐模块，否则门禁失败。
5. `layout.json` 只是兼容层，由 `--split` 维护，不要手工编辑。
