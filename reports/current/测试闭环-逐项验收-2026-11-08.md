## 四、门禁接线：A-3

`tools/gate.sh` 在索引一致性检查之后新增一步：

```bash
PYTHONPATH="tools;${PYTHONPATH:-}" "$PYTHON" -B tools/kb_quality_gate.py
```

`tools/kb_quality_waivers.json` 逐项登记 6 类存量欠账，每条含 `reason` / `evidence` / `plan` /
`reviewBy` / `observed` / `maxAllowed`。**豁免只表示暂不阻断交付，不表示已核验或已修复。**
`tools/kb_quality_gate.py` 对以下情况一律 `exit=1`：未登记的新失败、已登记项超过 `maxAllowed`、
豁免字段缺失、豁免过 `reviewBy` 未复核。欠账归零时提示删除豁免条目。

负例注入实测（临时副本在 F 盘，未改真实知识库）：

| 负例 | 注入方式 | 结果 |
| --- | --- | --- |
| 欠账恶化 | 让另一组两行简介相同，`duplicate_description_rows` 2 → 5 | `exit=1`，报「当前 5 > 允许上限 2」 |
| 未登记新失败 | 把一条空票价改成占位字符串 `暂无` | `exit=1`，报 `UNREGISTERED placeholder_values=1` |
| 豁免过期 | 把一条 `reviewBy` 改成 2020-01-01 | `exit=1`，报「已到期，必须复核并更新或销项」 |
| 正例 | 真实 `data/china_attractions.json` | `exit=0`，6 类存量欠账均为 `WAIVED` |

治理审计本身 `kb.quality_report --strict` 仍是 `exit=1`（6 类失败的事实没有改变），
只是现在由门禁区分「已登记的存量」与「新增回归」，不再让 6 类失败静默滑过交付。

## 五、模型成功路径：B-5 的诚实边界

本机没有 `DEEPSEEK_API_KEY`。本轮新增 `tools/model_success_probe.py`：在 127.0.0.1 起一个
OpenAI 兼容桩，用真实 jar 服务、真实 HTTP、真实会话走一次 `POST /api/agent/plan`。

```json
{
  "mode": "local_openai_compatible_stub",
  "realApiKeyUsed": false,
  "httpStatus": 200,
  "elapsedMs": 198.3,
  "stubCalls": 1,
  "stubRequest": {
    "model": "probe-model", "temperature": 0.3, "max_tokens": 800,
    "stream": false, "messageRoles": ["system", "user"],
    "userPromptChars": 1990, "requestBytes": 5071
  },
  "advice": "（本地桩输出）按候选景点整理两日行程建议；票价与开放时间以知识库标注为准，未知项不按免费处理。",
  "sources": ["本地景点知识库", "DeepSeek probe-model"],
  "dailySchedules": 2
}
```

断言：`advice` 原样回传桩输出、`sources` 标注模型来源、`notices` 不含「未配置模型密钥」、
`/api/agent/status` 的 `modelConfigured=true`。桩侧验证了 Bearer 头，输出不打印密钥原文。

**结论边界**：这证明「密钥可用时模型建议确实会生成并回传」，**不证明真实 DeepSeek 密钥可用**，
也不覆盖自然语言提取与按天编排（仍由规则完成）。B-5 因此记为**部分销项**，
真实密钥实测需要用户提供密钥或授权在隔离环境调用，且不得把本段写成「真实密钥已实测」。

> 工程坑：Java `RestTemplate` 默认用 `Transfer-Encoding: chunked`，本地桩若只按
> `Content-Length` 读请求体，会读到空串并返回 400。桩必须支持 chunked 分块读取。
