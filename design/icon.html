01

主标四态

同一组路径，四种使用环境。小尺寸与单色印刷不另画一套，只做减法。

Full · 标准
网页顶栏、启动图、文档封面。纸底 + 墨绿 + 赤陶。
#mark-full
Mono · 单色
传真、印章、单色印刷。山径改虚线，不靠颜色区分层次。
#mark-mono
Inverse · 深底
深色工具栏、App 图标底板。落点改用浅陶以保持对比度。
#mark-inverse
Micro · 16px
浏览器标签页。只留印框、折线、落点，线宽加倍。
#mark-micro

04

规则与自检

反 AI 味清单、对比度、动效降级逐项核过，不靠目测结论。

设计与交付自检
定调自然有机 + 刻石印章。展示字 Fraunces / 思源宋体回退，正文 Karla / 思源黑体回退；两者都不在默认字体清单内。通过
图标语义25 个符号全部对应实际动作，无纯装饰图标；通用线性图标集特征（统一圆角卡、居中装饰、无含义星形）均避开。通过
对比度墨绿 #1E4A3E 对纸 #F7F4EE ≈ 8.9:1；赤陶 #B4542A 对纸 ≈ 4.5:1；深底图形用 #FCFAF5 与 #E3C4B1。通过
构成首屏巨型主标旋转 -4 度并冲出栅格；区块用发丝规则线分隔，没有等圆角卡片阵列。通过
氛围纸纹 SVG 颗粒 4.5% 正片叠底 + 两道低透明度径向渐变，非纯色平铺。通过
动效一次 4 组入场编排，间隔 80ms，缓动 cubic-bezier(0.16,1,0.3,1)；hover 只动 transform 与 color；prefers-reduced-motion: reduce 全关。通过
状态默认 / 悬停 / 按下 / 聚焦可见 / 禁用 / 深底 / 单色 / 空尺寸，共 8 态可见。通过
可访问性唯一 h1、语义地标、:focus-visible 2px 描边、所有按钮 ≥44px、aria-pressed 与 aria-hidden 到位。通过
响应式375 / 768 / 1440 三档有独立构成答案：主标从浮层改为右对齐块，矩阵与图标网格按 3 / 4 / 6 列重排。通过
